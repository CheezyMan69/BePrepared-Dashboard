# BePrepared-Dashboard

The Dashboard for preparing in the morning!

A place to find all your necessary info before going out! Made to be compact and easy to follow.

## What would this display?

- Weather
- Public Transport Information (S-Bahn timings)
- Route to most visited locations
- Current news (maybe?)
- and more to come...!

## How it will be made?

- React.js
- Node.js
- Raspberry Pi

Both a physical dashboard and a website for quick access!
